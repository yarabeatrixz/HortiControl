# Back-end

Pasta reservada para a API do HortiLink.

Comece por [`../docs/BACKEND.md`](../docs/BACKEND.md): entidades, valores fixos, operações (caso de uso → rota sugerida), validações e checklist de segurança. As regras de negócio de referência estão em [`../frontend/src/0-domain/regras.js`](../frontend/src/0-domain/regras.js) (com testes).

Ao criar a API, adicione aqui: stack escolhida, como rodar, variáveis de ambiente (`.env.example`) e um workflow próprio em `.github/workflows/`.
